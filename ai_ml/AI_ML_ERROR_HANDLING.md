# AI/ML Machine-Readable Rejection Codes & Error Handling

### Explicit Rejection Codes:
- `EMPTY_POINT_CLOUD`
- `INSUFFICIENT_POINTS_LESS_THAN_20`
- `invalid_geometry_footprint_too_small` (Footprint $< 4.0	ext{m}^2$)
- `insufficient_vertical_extent` (Height $< 2.0	ext{m}$)
- `implausible_density` (Density $< 0.2	ext{ pts/m}^2$)
- `low_semantic_confidence` (Confidence $< 0.30$)
